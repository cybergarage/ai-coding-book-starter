# 神経衰弱ゲーム仕様

## 目的

ブラウザで遊べる、1人用の神経衰弱ゲームを作成します。追加のサーバーや外部APIを使用せず、スタータープロジェクトだけで実行できるようにします。

## 技術条件

- TypeScript、HTML、CSSを使用する
- UIフレームワークを追加しない
- Viteの開発サーバーで動作する
- ゲームの状態遷移とDOM操作を分離する
- ゲームの状態遷移をVitestでテストできる構造にする
- `npm run typecheck`、`npm test`、`npm run build`が成功する

## ゲーム盤

- 4行4列の16枚のカードを表示する
- 8種類の絵柄を2枚ずつ使用する
- ゲーム開始時とリセット時にカードをシャッフルする
- テストではカードの並びを明示的に指定できる

## カードの状態

カードは次のいずれかの状態を持ちます。

- 裏向き
- 一時的に表向き
- 一致済み

## カードを選択する

- 裏向きのカードを選択すると表向きになる
- 一致済みのカードを選択しても状態は変わらない
- すでに表向きのカードを再度選択しても状態は変わらない
- 1枚目と2枚目に異なるカードを選択する
- 2枚目を選択した時点で手数を1増やす

## 一致した場合

- 2枚の絵柄が同じ場合は一致済みにする
- 一致済みのカードは表向きのままにする
- 次のカードを選択できるようにする

## 一致しなかった場合

- 2枚の絵柄が異なる場合は、両方を800ミリ秒間表示する
- 表示中はほかのカードを選択できない
- 800ミリ秒後に両方を裏向きへ戻す
- その後、次のカードを選択できるようにする

## ゲームクリア

- 8組すべてが一致したらゲームクリアとする
- ゲームクリアを画面上に表示する
- 最終的な手数を表示する

## リセット

- リセットボタンを表示する
- リセットすると、カード、手数、選択状態、入力のロック、ゲームクリア状態を初期化する
- 判定待ちのタイマーがある場合は無効化する
- 新しいカード配置でゲームを開始する

## 画面

- ゲーム名を表示する
- 現在の手数を表示する
- 4行4列のカードを表示する
- リセットボタンを表示する
- ゲームクリア時にメッセージを表示する
- 320ピクセル幅の画面でも横スクロールせず操作できる

## アクセシビリティ

- カードとリセットには`button`要素を使用する
- キーボードだけでもカードを選択できる
- カードの状態を支援技術が識別できるラベルを付ける
- 色だけでカードの状態を表現しない

## 対象外

- オンラインランキング
- ユーザー登録
- データの永続化
- バックエンド

- 外部画像や外部API
