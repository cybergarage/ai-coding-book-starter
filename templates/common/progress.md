# 作業進捗

## 目的

`spec.md`の神経衰弱ゲームを実装し、`test.md`の確認項目を満たします。

## 作業規則

- `spec.md`と`test.md`の内容を変更しない
- 仕様にない機能を追加しない
- 新しい依存関係は、既存の構成では実現できない場合だけ追加する
- `.env`、認証情報、作業ディレクトリ外のファイルへアクセスしない
- 破壊的なGit操作を実行しない
- 確認できた事実だけをこのファイルへ記録する

## 許可された確認コマンド

```console

npm run typecheck
npm test
npm run build
```

## 停止条件

次のいずれかで作業を停止します。

- 自動確認がすべて成功し、実施可能なブラウザ確認が完了した
- 仕様が矛盾し、合理的な仮定では進められない

- 同じ原因による失敗が3回続き、追加情報なしでは進められない
