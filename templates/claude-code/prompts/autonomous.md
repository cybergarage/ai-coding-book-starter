# 仕様とテストで自律的に改善する

`spec.md`、`test.md`、`progress.md`を確認してください。

`spec.md`の機能を実装し、`test.md`に従ってテストを作成してください。実装、型検査、テスト、ビルド、修正を反復し、確認できた結果を`progress.md`へ記録してください。

次の条件を守ってください。

- `spec.md`と`test.md`を変更しない
- 仕様にない機能を追加しない
- 作業ディレクトリの外へアクセスしない
- 破壊的なGit操作を実行しない
- 実施していないブラウザ確認を完了扱いにしない
- 停止条件に達したら、完了項目、未完了項目、実行結果を報告する
