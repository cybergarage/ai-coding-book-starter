# 神経衰弱ゲーム テスト仕様

## 方針

ゲームの状態遷移はVitestによる単体テストで確認します。カードの並びを固定し、乱数に依存しないテストにします。DOMの見た目と操作感はブラウザで確認します。

## 自動テスト

### 初期状態

- 16枚のカードが存在する
- 8種類の絵柄が2枚ずつ存在する
- すべてのカードが裏向きである
- 手数が0である
- ゲームクリアではない
- 入力がロックされていない

### 1枚目の選択

- 裏向きのカードを選択すると表向きになる
- 1枚目だけでは手数が増えない
- 同じカードを再度選択しても状態が変わらない
- 一致済みのカードを選択しても状態が変わらない

### 一致

- 同じ絵柄の2枚を選択すると一致済みになる
- 2枚目を選択すると手数が1増える
- 一致したカードは表向きのまま残る
- 判定後に次のカードを選択できる

### 不一致

- 異なる絵柄の2枚を選択すると入力がロックされる
- 2枚目を選択すると手数が1増える
- ロック中に別のカードを選択しても状態が変わらない
- `vi.useFakeTimers()`を使用し、800ミリ秒の時間経過を実時間待ちなしで再現する
- 799ミリ秒経過した時点では、2枚が表向きで入力がロックされたままである
- 800ミリ秒経過した時点で、2枚が裏向きへ戻る
- 不一致を解決すると2枚が裏向きへ戻る
- 不一致を解決すると入力ロックが解除される

### ゲームクリア

- 最後の1組が一致するとゲームクリアになる
- クリア後も最終手数が保持される

### リセット

- カードがすべて裏向きになる
- 手数が0になる
- 選択状態がなくなる
- 入力ロックが解除される
- ゲームクリア状態が解除される
- 指定したカード配置で初期化できる

## コマンドによる確認

次のコマンドがすべて終了コード0で完了することを確認します。

```console
npm run typecheck
npm test
npm run build
```

## ブラウザによる確認

- 16枚のカードが4行4列で表示される
- 一致と不一致の動作を確認できる
- 不一致のカードが約800ミリ秒表示される
- 手数が画面に反映される
- すべて一致するとクリアメッセージが表示される
- リセット後に新しいゲームを開始できる
- キーボードだけでカードとリセットを操作できる
- 裏向き、表向き、一致済みの状態を支援技術向けラベルで識別できる
- 裏向きのカードのラベルから絵柄を特定できない
- 320ピクセル幅で横スクロールが発生しない

ブラウザで確認していない項目を、自動テストの成功だけで完了扱いにしません。
