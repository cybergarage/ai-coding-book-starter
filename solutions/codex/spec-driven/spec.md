# 神経衰弱ゲーム仕様

## 目的

ブラウザで遊べる、1人用の神経衰弱ゲームを作成します。追加のサーバーや外部APIを使用せず、スタータープロジェクトだけで実行できるようにします。

## 技術条件

- TypeScript、HTML、CSSを使用する
- UIフレームワークを追加しない
- Viteの開発サーバーで動作する
- ゲームの状態遷移とDOM操作を分離する
- ゲームの状態遷移をVitestでテストできる構造にする
- 不一致時の表示保持は標準の`setTimeout`と`clearTimeout`で実装し、Vitestのフェイクタイマーで時間経過を再現できる構造にする
- `npm run typecheck`、`npm test`、`npm run build`が成功する

## ゲーム盤

- 4行4列の16枚のカードを表示する
- 8種類の絵柄を2枚ずつ使用する
- 絵柄はUnicode絵文字など、外部リソースを使わず表示できる方法で表現する
- ゲーム開始時とリセット時にカードをシャッフルする
- テストではカードの並びを明示的に指定できる
- ゲームの初期化処理は、順序を固定した山札を受け取れる構造にする
- 山札を指定しない通常のゲーム開始時だけシャッフルする

## カードの状態

カードは次のいずれかの状態を持ちます。

- 裏向き
- 単独表向き（1枚目を選択した後、2枚目を選択できる状態）
- 判定待ち表向き（不一致の2枚を表示中で、ほかのカードを選択できない状態）
- 一致済み

## カードを選択する

- 裏向きのカードを選択すると表向きになる
- 一致済みのカードを選択しても状態は変わらない
- すでに表向きのカードを再度選択しても状態は変わらない
- 判定待ち表向きのカードがある間は、ほかのカードを選択しても状態は変わらない
- 1枚目と2枚目に異なるカードを選択する
- 2枚目を選択した時点で手数を1増やす

## 一致した場合

- 2枚の絵柄が同じ場合は一致済みにする
- 一致済みのカードは表向きのままにする
- 一致判定後は遅延を挟まず、即座に一致済み状態にする
- 次のカードを選択できるようにする

## 一致しなかった場合

- 2枚の絵柄が異なる場合は、2枚目を選択した時点から両方を800ミリ秒間表示する
- 799ミリ秒までは両方を表向きのままにし、ほかのカードを選択できないよう入力をロックする
- 800ミリ秒到達時に両方を裏向きへ戻し、入力のロックを解除する
- その後、次のカードを選択できるようにする

## ゲームクリア

- 8組すべてが一致したらゲームクリアとする
- ゲームクリアを画面上に表示する
- 最終的な手数を表示する
- ゲームクリア後は、リセット以外のカード選択では状態と手数を変更しない

## リセット

- リセットボタンを表示する
- リセットすると、カード、手数、選択状態、入力のロック、ゲームクリア状態を初期化する
- 判定待ちのタイマーがある場合は無効化する
- 判定待ち中にリセットした場合、リセット前のタイマー処理が新しいゲーム状態へ影響しないようにする
- リセットボタンを選択した場合はカードを再度シャッフルしてゲームを開始するが、直前と異なる配置になることまでは保証しない
- テストからは、順序を固定した山札を指定してリセットできる構造にする

## 画面

- ゲーム名を表示する
- 現在の手数を表示する
- 4行4列のカードを表示する
- リセットボタンを表示する
- ゲームクリア時にメッセージを表示する
- 320ピクセル幅の画面でも横スクロールせず操作できる

## アクセシビリティ

- カードとリセットには`button`要素を使用する
- キーボードだけでもカードを選択できる
- カードの状態を支援技術が識別できるラベルを付ける
- 裏向きのカードのラベルには絵柄の情報を含めない
- 色だけでカードの状態を表現しない

## 対象外

- 対戦機能
- オンラインランキング
- ユーザー登録
- データの永続化
- バックエンド
- 効果音
- 外部画像や外部API
